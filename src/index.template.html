    How this was built and what to trust.
    • Data compiled September 2026 from kalaari.com page metadata (portfolio, team, why-we-invested, fellowship, CXXO) surfaced through search, plus press coverage. The site itself could not be fetched directly from the build environment, so treat each entry as a lead with its source, not a filing.
    • Founder ages: reported means a dated public source states an age; estimated means derived from a graduation year or career length. Nothing here is a verified date of birth.
    • Kalaari says 160+ companies; this file traces of them with enough detail to show. The rest are older Fund I–II positions without a live portfolio page.
    • Refresh: run python scripts/scrape_kalaari.py from a machine that can reach kalaari.com, review the diff in data/kalaari.json, then python scripts/build.py.
